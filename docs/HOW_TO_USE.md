# How to open and use the study maps

## Open a map
**Fastest:** click the "Open" link for a domain in the README. Excalidraw loads the file straight from this repo in your browser.

**Download and open:**
1. Download the `.excalidraw` file from `maps/` (open the file on GitHub, then the download icon, or clone the repo).
2. Go to https://excalidraw.com, then Menu → Open (or drag the file onto the canvas).

**Other tools:** VS Code ("Excalidraw" extension), Obsidian (Excalidraw plugin).

## Navigate a big board
- Boards are about 2,400 px wide and 10,000+ px tall. Zoom to fit width on a wide monitor.
- Use **Scroll** to move down, **Ctrl/Cmd + scroll** to zoom, **Space + drag** to pan.
- Press **Ctrl/Cmd + F** inside Excalidraw to search text on the board.

## Make it yours
- Everything is editable. Add notes, recolour weak areas, delete what you already know.
- Save your edited copy to keep your progress (Menu → Save to your computer).

## Colour and section guide
Each board follows the same order: Coverage → Core concepts → Discriminators → Decision matrix → Traps → Glossary → Flashcards → Scenario Q&A.

## Print or export
Menu → Export image (PNG/SVG). For printing, export one section at a time by selecting it first.
