# Contributing

Thanks for helping make these maps more accurate.

## Good contributions
- Corrections to names, flags, limits or numbers, **with a link to the official doc or course page**.
- Missing task statements or topics, with a suggested panel.
- Better traps, flashcards or scenario questions that you wrote yourself.
- Typos and clarity fixes.

## Please do not
- Submit real or leaked exam questions, or anything covered by an exam NDA.
- Paste copyrighted course material word for word.

## How to propose a change
1. Open an issue describing the fix and the source.
2. For a pull request, edit the `.excalidraw` file in Excalidraw, export with **Save to** (keep the same filename), and describe what changed in the PR. Keep one topic per PR so diffs stay reviewable.
3. If a fact is unverified, mark it `VERIFY` on the board.
